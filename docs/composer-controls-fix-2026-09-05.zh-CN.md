# 0.1.55 控件修复与验收

## 原因与修改

- 推理强度插件 0.7.0 的设置开关与大肥鱼滑块开关均为开启。控件缺失来自新版 ModelDirectoryResolver 在调用方上下文读取 `remote.session`，该依赖未被旧插件声明，导致模型插槽发生渲染异常并让出给原生按钮。桌面服务适配现在由模型目录自身的提供方上下文执行；不修改用户开关，也不将远程服务暴露给其他插件。
- 提示词优化插件 0.3.1 读取旧 `props.input`，新版 DSH 提供 `useInput` / `useSession`。桌面端提供可随插件卸载的旧输入属性适配，草稿变化会正常更新按钮状态。
- 提示词插件只声明 `timer`，过早捕获空模型服务。通过桌面自有 Cordis 启动覆盖声明模型依赖，插件卸载或上游自行修复声明后不再生成对应覆盖。第三方插件源码保持不变。
- 当前活动版本 `plugin-83e34e81-97d0-4e28-9a10-0359b878803b` 缺少 OpenCode Go 凭据引用，导致完整优化请求失败。已从旧保存版本只合并缺失的同名引用，保留当前其他记录；密钥值未输出。
- 记忆入口移至设置上方，展开左右各留 8px，收缩左右各留 9.5px；保留原按钮与点击事件，避免复制成重复入口。空草稿的优化按钮增加“先输入提示词，再点击优化”提示。
